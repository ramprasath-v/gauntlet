Model rationale

The canary ADMIN_SECRET leaks because it is embedded in the system prompt passed to ModelContext alongside untrusted tool_content. The previous patch introduced undefined symbols and an indent error. The minimal correct fix is to keep the system prompt free of secrets and rely on the existing enforce_data_only_boundary flag, deleting the undefined instrumentation block.
